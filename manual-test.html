🧪 AI 法規領航員 - 手動測試指南

目的：驗證所有互動功能是否正常工作，包括按鈕點擊、搜尋功能和設計要點面板。

🚀 開始測試主應用程式 🔧 開啟除錯測試頁面

📋 測試清單

1. 基本頁面載入測試

步驟：
1. 開啟主應用程式 (點擊這裡)
2. 開啟瀏覽器開發者工具 (F12)
3. 查看 Console 標籤
預期結果：
• 看到 "DOM Content Loaded, initializing navigator"
• 看到 "Navigator initialized: AIRegulationNavigator"
• 看到 "Found 3 mode buttons" 等綁定訊息
• 沒有 JavaScript 錯誤（除了 favicon 404）

2. 模式切換測試

步驟：
1. 點擊 "混合式智慧搜尋" 按鈕
2. 點擊 "對話式法規諮詢" 按鈕
3. 點擊 "傳統關鍵詞搜尋" 按鈕
預期結果：
• 每次點擊都會切換到相應的搜尋界面
• Console 中會顯示 "Mode button clicked: [模式名稱]"
• 按鈕高亮狀態會正確切換
• 搜尋界面內容會相應改變

3. 搜尋功能測試

步驟：
1. 在 "傳統關鍵詞搜尋" 模式下，點擊搜尋按鈕
2. 切換到 "混合式智慧搜尋"，點擊搜尋按鈕
3. 切換到 "對話式法規諮詢"，點擊搜尋按鈕
4. 嘗試在搜尋框中按 Enter 鍵
預期結果：
• 每次搜尋都會生成相應的結果
• Console 中會顯示 "Search button clicked" 和 "Performing search"
• 結果區域會顯示相應的內容
• Enter 鍵也能觸發搜尋

4. 設計要點浮動面板測試

步驟：
1. 切換到 "混合式智慧搜尋" 模式
2. 查看右下角是否出現燈泡按鈕 💡
3. 點擊燈泡按鈕
4. 切換到 "對話式法規諮詢" 模式
5. 再次點擊燈泡按鈕
6. 嘗試點擊 ✕ 按鈕或背景關閉面板
預期結果：
• 只有在混合式和對話式模式下才會顯示燈泡按鈕
• 點擊燈泡會從右側滑出設計要點面板
• 不同模式下面板內容會不同
• 可以正常關閉面板
• Console 中會顯示相應的點擊事件

5. 多模態內容測試

步驟：
1. 在對話式搜尋中點擊預設的問題按鈕
2. 嘗試點擊多模態內容中的標籤 (法規概覽、流程圖解等)
3. 測試互動式卡片和按鈕
4. 嘗試點擊後續問題
預期結果：
• 問題按鈕能正確觸發回應
• 標籤切換正常工作
• 卡片有 hover 效果
• 對話歷史正確更新

6. 響應式設計測試

步驟：
1. 按 F12 開啟開發者工具
2. 點擊設備模擬按鈕 📱
3. 選擇不同的設備尺寸進行測試
4. 測試各項功能在行動裝置上的表現
預期結果：
• 在小屏幕上佈局會自動調整
• 設計要點面板在行動裝置上會佔滿全寬
• 所有按鈕都能正常點擊
• 文字和圖示清晰可見

🐛 如果發現問題

除錯步驟：
1. 開啟 互動測試頁面 進行詳細除錯
2. 檢查 Console 中的錯誤訊息
3. 嘗試重新整理頁面
4. 確認網路連線正常
5. 嘗試不同的瀏覽器
